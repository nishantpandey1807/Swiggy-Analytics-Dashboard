# Swiggy-Analytics-Dashboard
An interactive Sales Analytics Dashboard developed to analyze Swiggy restaurant data and identify important business trends and performance insights.
Key Highlights:

📊 Overall sales and order performance
⭐ Customer rating analysis
🍴 Veg vs Non-Veg sales comparison
📈 Monthly, daily, and weekly sales trends
🗺️ State-wise sales analysis
🏙️ Top-performing cities by sales
🏪 Restaurant and category-level analysis
📅 Quarter-wise comparison of sales, ratings, and orders
🔍 Interactive filters for months, restaurants, and categories
